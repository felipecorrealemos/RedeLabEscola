Certificado de segurança RedeLab

Se o navegador mostrar “Não seguro”, instale o certificado público RedeLab como confiável antes de acessar o jogo e o monitor.

Baixar certificado RedeLab

Como instalar no Windows

  1. Baixe o arquivo redelab.crt.
  2. Abra o certificado.
  3. Clique em Instalar Certificado.
  4. Escolha Usuário Atual.
  5. Escolha Colocar todos os certificados no repositório a seguir.
  6. Selecione Autoridades de Certificação Raiz Confiáveis.
  7. Conclua a instalação.
  8. Feche completamente o navegador e abra-o novamente.
