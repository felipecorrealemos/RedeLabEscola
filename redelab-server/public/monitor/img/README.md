# Logo do monitor

Quando o logo oficial estiver disponível, salve-o nesta pasta como `redelab-logo.svg` ou `redelab-logo.png`.

Depois, em `public/monitor/index.html`, defina o `src` do elemento `#brandLogo`, remova a classe `d-none` da imagem e adicione `d-none` ao elemento `#brandIconFallback`. O quadrado azul e o dimensionamento atual já aceitam a imagem sem outras mudanças de layout.
